API

Required. To create an API key, follow the Setup Guide tab once and then paste the key here.

Content

Each entry becomes its own folder in the YouTube channel. Type something into the box and click Add (or press Enter). Click × on a chip below to remove it.
Accepted formats:
  • @handle — e.g. @MrBeast (cheap, recommended)
  • Channel ID — starts with UC...
  • Public or unlisted playlist ID — starts with PL..., UU... or OL...
  • Search text — plain text that is not an ID-like value, runs as a YouTube search (each uncached results page uses one call from the separate daily search limit)
You can paste a comma- or line-separated list to add several at once.
Public or unlisted playlists that should appear as their own top-level folder and be checked regularly for new videos. YouTube's private Watch Later and watch-history playlists cannot be read through the Data API.
Each fetched page of up to 50 items uses one regular API unit. A check can fetch up to five pages (see poll interval below).
How often the plugin checks each auto-refreshed playlist. Default 3 minutes. At that interval one playlist uses about 480 regular units per day when it fits on one page, or about 2,400 units before retries when all five pages must be fetched.

Folders

Choose which extra folders appear in the YouTube channel root, alongside your saved channels and playlists.

Display

Country used for the Trending and Categories folders. With YouTube default, Trending uses YouTube's API default and Categories use the US catalog as a fallback.
Filter the Trending folder to a single category. All keeps the unfiltered trending feed. The Categories Browser (if enabled) is unaffected by this setting.
Order videos inside each saved channel folder. Date shows newest first through the low-cost uploads playlist (recommended). View count is most popular first. Rating uses YouTube's rating order. Relevance is YouTube's default mixed ranking. Every uncached non-date results page uses one call from the separate daily search.list limit.

Limits

How many videos to load into each folder. Higher values mean more videos to scroll through, but also slightly slower refreshes and more quota used.
Cap on videos loaded per saved channel and per playlist (1–150). Default 50. Higher limits fetch more listing and detail pages, so the exact cost depends on the folder.
Cap on results per search-text entry (1–150). Default 50. Every uncached page of up to 50 results uses one call from the separate default limit of 100 search.list calls per day, so prefer @handles or channel IDs.

Setup Guide

Click the YouTube Data API v3 button first, then follow the marked steps below.

Open YouTube Data API V3 Open Google Cloud Credentials
1. Enable YouTube Data API v3
Use the green Open YouTube Data API V3 button above to open this page, then click Enable.
2. Create credentials
After the API is enabled, click Create credentials on the API details page.
3/4. Select public data and click Next
In the credential type form, keep YouTube Data API v3 selected, choose Public data, then click Next.
5. Copy the API key
Click the copy icon next to the generated API key.
6. Paste the key into the plugin
Switch back to the Settings tab, paste the copied key into YouTube Data API Key, then add your channels or playlists. Changes are saved automatically.
7. Open the API key settings
Click the Open Google Cloud Credentials button above, then click the three-dot menu on the right side of your newly created API key and choose Edit.
8. Restrict the key to YouTube Data API v3
Open the API restrictions field, search for YouTube Data API v3, select it, click OK, then click Save.
