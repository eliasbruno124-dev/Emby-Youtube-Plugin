API

Required. Get a free key at console.cloud.google.com → create project → enable YouTube Data API v3 → create an API key. The free tier gives you 10,000 quota units per day, which is more than enough for normal viewing. See the Setup Guide tab for step-by-step instructions.

Content

Each entry becomes its own folder in the YouTube channel. Type something into the box and click Add (or press Enter). Click × on a chip below to remove it.
Accepted formats:
  • @handle — e.g. @MrBeast (cheap, recommended)
  • Channel ID — starts with UC...
  • Playlist ID — starts with PL...
  • Search text — anything else, runs as a YouTube search (costs 100 quota units per refresh, use sparingly)
You can paste a comma- or line-separated list to add several at once.
Playlist IDs that should appear as their own top-level folder and be checked regularly for new videos. Use this for queue-style playlists (your private Watch Later, "to watch", etc.) where new entries should show up automatically without waiting for the next full refresh.
Each playlist costs 1 quota unit per check (see poll interval below).
How often (in minutes) the plugin checks each Watch Later playlist for new videos. Default 3 min. Lower values pick up new entries faster but use more daily quota — at 3 min × 1 playlist that's about 480 units per day, well within the free 10,000.

Folders

Choose which extra folders appear in the YouTube channel root, alongside your saved channels and playlists.

Display

Country used for the Trending and Categories folders. Leave on YouTube default to use the region YouTube infers from your server's IP.
Filter the Trending folder to a single category. All keeps the unfiltered trending feed. The Categories Browser (if enabled) is unaffected by this setting.
Order videos inside each saved channel folder. Date shows newest first (recommended). View count is most popular first. Rating uses YouTube's like-based score. Relevance is YouTube's default mixed ranking.

Limits

How many videos to load into each folder. Higher values mean more videos to scroll through, but also slightly slower refreshes and more quota used.
Cap on videos loaded per saved channel and per playlist (1–150). Default 50. Loading 150 costs about 4 quota units per refresh.
Cap on results per search-text entry (1–150). Default 50. Each search costs 100 quota units regardless of result count, so prefer @handles or channel IDs when possible.
How many of the newest videos to pull from each saved channel into the Recently Added feed (1–25). Default 10. Only relevant if "Show Recently Added" is enabled.

Setup Guide

Follow these steps to create a YouTube Data API key. Add screenshots to the exact placeholder filenames shown below if you want this guide to become visual later.

Open YouTube Data API v3 Open Google Cloud Credentials
1. Open Google Cloud Console
Go to Google Cloud Console and sign in with the Google account you want to use for the API key. The direct API library link is above.
Screenshot here: docs/screenshots/setup-api-key-01-console.png
2. Create or select a project
Click the project selector in the top bar. Choose an existing project or create a new one, for example "Emby YouTube Plugin".
Screenshot here: docs/screenshots/setup-api-key-02-project.png
3. Enable YouTube Data API v3
Open APIs & Services, then Library. Search for "YouTube Data API v3", open it, and click Enable.
Screenshot here: docs/screenshots/setup-api-key-03-enable-api.png
4. Open Credentials
Go to APIs & Services, then Credentials. This is where Google lets you create and manage keys for the selected project.
Screenshot here: docs/screenshots/setup-api-key-04-credentials.png
5. Create the API key
Click Create credentials, choose API key, then copy the generated key. You can restrict it to YouTube Data API v3 afterward if you want a tighter setup.
Screenshot here: docs/screenshots/setup-api-key-05-create-key.png
6. Paste and save in Emby
Return to the Settings tab, paste the key into YouTube Data API Key, add your channels or playlists, then click Save.
Screenshot here: docs/screenshots/setup-api-key-06-emby-settings.png
